# Portfolio Monte-Carlo simulation

## What This Simulation Does

This application simulates thousands of possible future market scenarios for a custom stock portfolio using **Monte Carlo methods** and historical return data. By adjusting asset weights, investment horizons, and initial capital, users can visualize potential portfolio growth, measure downside risk (Value at Risk), and identify the optimal risk-to-reward allocation in real time.

## Features

- **Core Functionality:** 1. Return & Risk Estimation from Historical Data.,2. Correlated Random Path Generation (Vectorized Simulation),3. Portfolio Optimization (Weights & Trade-Offs),4. Risk & Outcome Metrics Across Paths,5. Interactive Exploration & Sensitivity Controls
  
- **Tech Stack:** Built using Python,numpy,pandas and streamlit.
- **Performance:** Fast, modular, and easy to deploy locally.
